# AutoStartup
依赖[.net 9.0](https://dotnet.microsoft.com/zh-cn/download/dotnet/9.0)

- 拖拽添加程序（仅限非管理员权限运行）
- 快捷添加Python程序、Python模块、cmd指令、powershell指令
- 服务退出后自动重启
- 轻量运行（仅限启动后不拉起WPF窗口）
- 托盘管理
- 美观WPF窗口
- 彩色控制台输出渲染（ANSI）
- 记录操作日志与控制台输出
- 隐藏控制台窗口
- 自动加入自启动注册表
